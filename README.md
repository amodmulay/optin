# Optin

A deals Progressive Web App (PWA) for the Indian and Turkish communities in Germany.

> Status: early setup. The detailed build plan will be tracked as GitHub issues.

## About

Optin helps people in the Indian and Turkish communities in Germany find and share deals, offers, and discounts from local businesses. It is delivered as a PWA so it installs on a phone home screen and works in the browser without an app store.

## Getting started

Setup steps will be added once the tech stack is chosen. For now:

```bash
git clone https://github.com/amodmulay/optin.git
cd optin
```
